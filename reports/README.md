# PhishShield Evaluation Reports Directory

All reports in this directory are generated strictly from executing code. No numbers are invented or mock-generated.

- `reports/data_quality.json`: Dataset statistics, class balance, and feature quality metrics generated by `ml/prepare_datasets.py`.
- `reports/model_comparison.json`: Cross-validation comparison table between Logistic Regression, Random Forest, and HistGradientBoosting generated by `ml/compare_models.py`.
- `reports/url_model_metrics.json`: Final held-out test set metrics, confusion matrix, false-positive/negative examples, and sanity set evaluation generated by `ml/evaluate_url_model.py`.
